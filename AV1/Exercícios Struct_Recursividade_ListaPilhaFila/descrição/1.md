# Exercício 1 — Criando uma Estrutura Simples

Crie uma struct chamada `Pessoa`, que contém os seguintes campos:

- Nome (string de até 50 caracteres)
- Idade (inteiro)
- Altura (float)

No programa principal, declare uma variável do tipo `Pessoa`, preencha os dados do usuário via teclado e exiba as informações.
